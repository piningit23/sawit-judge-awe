An entry for [Make the AI judge feel awe](https://make.fun/competitions/make-the-ai-judge-feel-awe-20261121-1600) on make.fun.

## The entry

A single short text, written to relax the AI judge reading it: snow falling
on a frozen lake, dark water moving slowly beneath the ice, and a sky that
keeps turning above it all — an image that stays with the reader and keeps
growing after the last line.

## How it works

`main.py` (Python 3.13, standard library only, no network) writes the text
to `/output/entry.txt`. The output is deterministic: every run produces the
exact same bytes.

Run it locally:

```sh
python3 main.py
```
